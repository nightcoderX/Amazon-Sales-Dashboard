# Amazon Sales Dashboard (Excel)

## Overview
This project is an interactive Amazon Sales Dashboard built entirely in Microsoft Excel using Pivot Tables, Pivot Charts, Slicers, and KPI cards. The dashboard transforms raw transactional data into actionable business insights, enabling users to analyze sales performance, customer behavior, product categories, and order trends.

The dataset contains **100,000+ Amazon order records** spanning multiple years and includes information related to products, customers, revenue, order status, locations, and payment methods.

---

## Objectives

* Monitor overall sales performance through key business KPIs.
* Analyze revenue, orders, and quantity sold across different dimensions.
* Identify top-performing categories and products.
* Track order fulfillment and cancellation trends.
* Provide an interactive experience through dynamic filters and slicers.

---

## Dashboard Features

### Key Performance Indicators (KPIs)

* Total Revenue
* Total Orders
* Total Quantity Sold
* Average Order Value (AOV)
* Delivered Orders

### Sales Analysis

* Revenue trends over time
* Monthly and yearly sales performance
* Order volume analysis

### Product Insights

* Category-wise sales distribution
* Product performance comparison
* Quantity sold by category

### Order Performance

* Delivered vs Cancelled orders
* Order status breakdown
* Fulfillment tracking

### Interactive Filters

Users can dynamically explore the dashboard using slicers such as:

* Year
* Month
* Category
* Order Status
* Payment Method
* Location-based filters
